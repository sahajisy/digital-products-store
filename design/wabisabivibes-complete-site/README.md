# Wabi Sabi Vibes — Complete HTML Design System

This package contains a multi-page static ecommerce prototype based on the supplied kawaii brand board.

## Pages
Home, Shop, Japan, Korea, Home & Living, Beauty & Self-Care, Gifts, Stationery, New Arrivals, Best Sellers, Product, Journal, Journal Post, About, Contact, FAQ, Shipping, Returns, Product Standards, Privacy Policy, Terms, Cart, Checkout, My Account.

## Separate website assets
All artwork is separated into `/assets/`:
- logo.svg
- favicon.svg
- hero.svg
- category banners
- product images
- trust icons
- social cards

## WordPress / WooCommerce conversion
1. Install WordPress + WooCommerce.
2. Use this design as the Elementor visual reference.
3. Create global colors and typography from `style.css`.
4. Use WooCommerce loops for Shop, category, new-arrival and best-seller grids.
5. Replace static product cards with dynamic WooCommerce product widgets/shortcodes.
6. Replace static Cart, Checkout and Account pages with native WooCommerce pages.
7. Connect the actual payment gateway, shipping zones, tax settings and dropshipping integration.
8. Replace placeholder legal/business details before launch.
9. Replace placeholder product artwork with supplier/product photography where available.
10. Keep the customer-facing brand as Wabi Sabi Vibes; show the actual legal business details in the footer, invoices and policies.

## Important
The static files are a design prototype, not a live payment or order-processing system.
