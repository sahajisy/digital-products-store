# Wabi Sabi Vibes HTML design

This is a standalone visual prototype based on the supplied kawaii brand asset board.

Files:
- index.html — homepage prototype
- assets.css — brand design tokens
- main.js — small prototype interactions

For WordPress/WooCommerce:
- Use the visual structure as the Elementor homepage reference.
- Replace sample product cards with WooCommerce product loops.
- Replace placeholder links with actual WooCommerce category/product URLs.
- Replace the newsletter alert with the chosen email integration.
- Replace emoji/placeholder illustrations with the final exported brand assets.
- Keep the legal/business information configurable.
